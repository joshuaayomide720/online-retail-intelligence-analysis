# online-retail-intelligence-analysis
End-to-end analysis of the Online Retail II dataset using Excel and Power BI to uncover sales performance, customer behavior, product trends, returns, and market opportunities.
The Online Retail II dataset was obtained from the UCI Machine Learning Repository. Dataset source:https://archive.ics.uci.edu/dataset/502/online+retail+ii. The original dataset is not included in this repository because of its file size.
